# Prompt Praktikum

Gunakan prompt berikut di Hermes Agent setelah skill OpenCode terpasang:

```text
Gunakan skill OpenCode untuk mengerjakan project pada folder ini.

Tujuan:
1. Buat landing page HTML responsif untuk bisnis layanan AI lokal.
2. Gunakan HTML, CSS, dan JavaScript tanpa framework.
3. Tambahkan bagian hero, layanan, alur kerja, dan tombol kontak.
4. Pastikan tampilan nyaman pada ponsel.
5. Tambahkan Dockerfile berbasis Nginx Alpine.
6. Tambahkan docker-compose.yml dengan port 8080.
7. Periksa sintaks JavaScript dan konfigurasi Docker.
8. Jangan menaruh API key atau data rahasia dalam project.

Laporkan file yang diubah dan hasil pengujiannya.
```

Jika menjalankan OpenCode secara langsung, masuk ke folder project, jalankan `opencode`, pilih model gratis melalui `/models`, lalu kirim tujuan yang sama.
